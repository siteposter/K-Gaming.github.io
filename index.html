Как к нам подключиться

Подключение к сайту и API

Чтобы подключиться к сайту, используйте HTTPS-адрес и авторизацию по токену. Ниже — пример кода для подключения из браузера и Node.js.

// Подключение к сайту K Gaming
const response = await fetch('https://k-gaming.example.com/api/v1/games', {
  headers: { 'Authorization': 'Bearer YOUR_API_TOKEN', 'Accept': 'application/json' }
});
const games = await response.json();
console.log(games);

// Node.js
import https from 'node:https';
const req = https.request('https://k-gaming.example.com/api/v1/games', { headers: { 'Authorization': 'Bearer YOUR_API_TOKEN' } }, res => { let d=''; res.on('data', c=>d+=c); res.on('end', ()=>console.log(JSON.parse(d))); });
req.end();

О K Gaming

Игровая полка без лишнего шума

K Gaming помогает находить популярные игры, знакомиться с жанрами и переходить к публичным отзывам. Оценки-рейтинги не присваиваются редакцией: впечатления в карточках являются краткими описаниями опыта, а источник пользовательских отзывов указан отдельно.
